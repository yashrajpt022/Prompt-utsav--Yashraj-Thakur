PROGRAMS

Four departments, one admission process

Each branch runs its own labs and project sequence, but shares the same first-year foundation courses.

Mechanical Engineering

Thermodynamics, manufacturing, and design — with a final-year capstone built and tested on campus, not just simulated.

  • Intake180 seats
  • Core labsCAD/CAM, Fluid Mechanics, Thermal
  • CapstonePhysical prototype required

PLACEMENT PARTNERS

Tata Motors, Bajaj Auto, L&T, Godrej Appliances

Civil Engineering

Structural analysis and site work from year two onward, including a semester embedded with a live construction contractor.

  • Intake120 seats
  • Core labsStructural, Geotech, Surveying
  • CapstoneSite-based design report

PLACEMENT PARTNERS

L&T Construction, Shapoorji Pallonji, PWD

Computer Engineering

Systems-first curriculum — data structures and OS internals before frameworks, with a mandatory open-source contribution in year three.

  • Intake240 seats
  • Core labsSystems, Networks, Data Engineering
  • CapstoneDeployed application, code reviewed

PLACEMENT PARTNERS

TCS, Persistent Systems, Zensar, local startups

Electrical Engineering

Power systems and control theory grounded in the state grid's own substations, visited each semester as coursework.

  • Intake120 seats
  • Core labsPower Systems, Control, Machines
  • CapstoneGrid-connected mini-project

PLACEMENT PARTNERS

MSEDCL, Siemens, ABB, Crompton Greaves
